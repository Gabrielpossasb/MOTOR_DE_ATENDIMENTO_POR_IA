Cada pergunta rodada aqui é uma chamada real à API e custa dinheiro. A contagem acima mostra o custo medido, não estimado.
As perguntas vêm de avaliacao.json, e "Salvar perguntas" reescreve esse arquivo — é o mesmo que o npm run avaliar lê.
Rodar por aqui não grava em logs/, de propósito: uma rodada parcial registrada como execução faria a seção de regressões do relatório comparar 3 perguntas contra as 24 da suíte e acusar falhas que não existiram. Para registrar histórico, use npm run avaliar -- <slug>.
